# Robot description licensing

The imported D2 robot source assets retain Apache-2.0; the preserved license, notice and provenance records are in UPSTREAM/. CERN-OHL-W-2.0 applies only to separately identifiable hardware contributions owned by Kinatric, not the imported design.

Kinatric-owned executable launch/build code and modifications are GPL-3.0-or-later. Full texts are in COPYING-HARDWARE and COPYING-SOFTWARE. No grant is made over third-party rights. Source Location: https://github.com/Kinatric/d2_rl_lab. Preserve source hashes and provide the preferred editable design source when distributing covered hardware.
